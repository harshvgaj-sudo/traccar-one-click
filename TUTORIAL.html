Traccar Personal Tracker

Your own location tracker. No Google account. No subscriptions. Your data stays on your PC.

Server: Traccar v6.16.0 (Apache-2.0) Android app: Colota v1.21 (recommended) / Traccar Client Viewer: Traccar Manager Network: Tailscale (GitHub login)

Read this first — the one honest caveat

The tracker server runs on your PC. When the PC is on, tracking is live. When the PC is off or asleep, the live view pauses. With Colota on Android this is minor: it queues points on the phone and back-fills them automatically when the PC returns — history is delayed, not lost. On iOS (Traccar Client) points during PC-off windows are not recorded. Keep the PC on (or plugged in with sleep disabled) for the best experience — and later, the same server can move to a small cloud VM for 24/7 tracking.

1

On the PC — run SETUP-TRACKER.bat

Double-click it. It does everything by itself:

  1. Downloads the official Traccar server (≈100 MB) and installs it as a Windows service that starts automatically with your PC
  2. Installs Tailscale — your private network that lets your phone reach this PC from anywhere, even on mobile data
  3. Opens a browser for Tailscale login — sign in with GitHub, NOT Google (one time only)
  4. Opens the Traccar dashboard

If the silent install fails, the script opens the normal installer — just click Next, Next, Finish, then run the script once more.

2

On the PC — secure the dashboard

  1. Open http://localhost:8082
  2. Login: user admin, password admin
  3. Top-right menu → Account → CHANGE THE PASSWORD (this is the only password protecting your data)
3

On the PC — run SHOW-PHONE-ADDRESS.bat

It prints the exact address your phone needs. It looks like:

http://100.x.y.z:8082

This is your PC's private Tailscale address. It works on home WiFi and outside on mobile data — same address, always. No port forwarding, and nobody outside your devices can reach it.

4

On the phone — install the app

  1. Android — recommended: Colota (modern simple UI, dark mode, no Google services, queues points while offline):
    APK v1.21.0 direct (43 MB): f-droid.org/repo/com.Colota_53.apk · or via the F-Droid app (search "Colota")
    When installing, allow "install unknown apps" for your browser (Android asks once).
  2. Android — alternative: Traccar Client (official, two-field simple):
    github.com/traccar/traccar-client/releases/download/v10.2.4/app-release.apk (v10.2.4, 68 MB)
  3. iPhone: install "Traccar Client" from the App Store (free) — iOS has no APK choice.
  4. Everyone: install Tailscale on the phone too (Play Store / App Store / tailscale.com) and sign in with the same GitHub account you used on the PC.
  5. Bonus: on any phone that should only VIEW the map, install Traccar Manager — one clean live-map screen, no tracking needed.
5

On the phone — two settings, that's all

  1. Colota: add a backend → choose Traccar as the type → Server URL = the address from Step 3 (e.g. http://100.x.y.z:8082) → the app has a device-ID / identifier field — copy that code. (Traccar Client: same two fields, leave Username/Password empty.)
  2. Press Start / enable tracking, and allow location permission "Allow all the time"
6

Back on the PC — see yourself move (the payoff)

  1. Dashboard → Devices → + Add → Name: your phone's name → Identifier: paste the code from the phone → Save
  2. Watch the dot appear and follow you live.

Repeat steps 4–6 for every phone you want to track. Each phone gets its own identifier automatically — that IS the login. No accounts anywhere.

7

Simple View — your clean personal map (built into this kit)

The stock dashboard is for fleets. For everyday use, open the Simple View — the setup script installs it automatically:

http://localhost:8082/simple-view.html

From anywhere on your phone (same Tailscale network): http://100.x.y.z:8082/simple-view.html. Login = same email/password as the dashboard.

  • One clean map + a card per device: status dot, speed, battery, "updated X ago"
  • Anything not updated in 10 minutes turns amber and says STALE — a frozen pin never lies to you
  • Dark mode by default, OpenStreetMap tiles (no Google, no API keys)

Make it reliable on Android (important)

  • Settings → Apps → Traccar Client → Battery → Unrestricted / Don't optimize — otherwise Android kills tracking to save battery (Xiaomi/Samsung/Oppo are the worst for this)
  • In the app: Accuracy = High, and keep the default interval (or set 30–60 seconds to save battery)

Troubleshooting

SymptomFix
Phone can't connectTailscale must be signed in on both PC and phone. Check the phone's Tailscale app is connected (toggle on).
Dot not movingBattery optimization killed the app (see above). Also check tracking is started in the app.
PC was off — is history lost?With Colota: no — it queues points on the phone and back-fills them when the PC returns. With Traccar Client/iOS: points during that window are not recorded.
Wrong address / 100.x.y.z changedRerun SHOW-PHONE-ADDRESS.bat — the address is stable but re-verify after reinstalling Tailscale.
Dashboard unreachableRun services.msc → find "traccar" → Start. Or rerun the setup script.
iOS updates sparseApple throttles background GPS on any app. This is Apple's limit, not the app's.
